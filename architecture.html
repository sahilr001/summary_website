Database /opt/earnote/readback.db (SQLite — single file, no separate server)

jobs
idINTEGER PKautoincrement

idINTEGER PKautoincrement
emailTEXTwho clicked the $9 button
planTEXT"pro_9" (no charge taken)
createdTEXTUTC ISO timestamp
Powers: pro_clicks in /stats — your conversion signal
Important: The database is a single file on the EC2 instance. If the instance is terminated without a backup, all data is lost. To back up: scp -i summary-website.pem ubuntu@13.207.58.206:/opt/earnote/readback.db ./readback.db
